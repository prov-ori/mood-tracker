# Проверка Mood Atlas 1.1

34 автоматические проверки: расчёты, даты, часовые пояса, пропуски, сон, валидация и восстановление снимков, экранирование, CSV, ошибки REST, сеансы, память вкладки, обработчики интерфейса и рендеринг. Команды: `npm test`, `npm run build`. Сборка запускает тесты автоматически через prebuild.

Тесты обработчиков используют минимальную имитацию DOM, а не браузер. Локальный сервер недоступен из облачного браузера. Реальный вход, печать PDF, мобильная вёрстка и взаимодействие с Supabase на опубликованном сайте требуют проверки. Чтение публикаций Vercel блокируется разрешениями команды.

Схема Supabase не менялась. Старые снимки отчётов совместимы. Полный список исправлений, свидетельства и границы проверки — в AUDIT.md, следующие функции — в ROADMAP.md.
